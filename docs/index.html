OmniEarth

Universal Open Multi-Modal Earth Observation, Hyperspectral Data Cube & Environmental Intelligence Engine.

GitHub Repository Get Started Author: Lokesh Kumar

Python SDK Astral uv / pip

Ultra-fast search and streaming downloads for satellite cubes and environmental feeds.

# Install with uv
uv add omniearth

# Python Usage
import omniearth as oe

client = oe.OmniEarth()

# Search DLR EnMAP Hyperspectral 224-band cubes
scenes = client.search(
    category="hyperspectral",
    bbox=[78.50, 20.65, 78.60, 20.72],
    max_cloud_cover=20
)

# Download 224-band Cloud-Optimized GeoTIFF
client.download(scenes[0], asset_key="SPECTRAL_IMAGE_COG")

Node.js & TypeScript pnpm / npm

Full-featured ESM TypeScript client for cloud functions, backends, and full-stack web applications.

# Install with pnpm
pnpm add omniearth

// TypeScript / ESM Usage
import { OmniEarth, Category } from "omniearth";

const client = new OmniEarth();

// Search Optical Sentinel-2 10m COGs
const scenes = await client.search({
  category: Category.OPTICAL,
  bbox: [78.50, 20.65, 78.60, 20.72],
  maxCloudCover: 10
});

// Download Visual RGB COG
await client.download(scenes[0], "visual", "./downloads");

Universal Command-Line Interface (CLI)

# Instant provider status & credential diagnostic
omniearth info

# Search Sentinel-2 L2A optical scenes
omniearth search --category optical --bbox 78.50 20.65 78.60 20.72 --max-cloud 10

# Search EnMAP Hyperspectral 224-band scenes
omniearth search --category hyperspectral --bbox 78.50 20.65 78.60 20.72

# Zero-config hourly weather & 3D soil moisture profile
omniearth search --category weather --point 78.55 20.68 --json
